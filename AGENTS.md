# Delivery preference

The application name is קלי קלוח, from לוח; the final letter is ח.

After completing and validating requested changes, commit and push all intended
changes to the production branch (`main`) and deploy them to the existing site.
The user has authorized this as the default workflow; no extra confirmation is
needed. Verify deployment when access is available and report any blockers.

# Tutorial videos (narration and music)

When producing a tutorial or demo video, follow `tutorial-video/PRODUCTION-PLAYBOOK.md`:
Hebrew neural narration (israwave + Nakdimon, timed to the captions), original
synthesized background music ducked under the voice, and the QC checklist.
Scripts live in `tutorial-video/scripts/`. Always keep no-music and no-voice
variants, and state plainly what was not verified by listening.
