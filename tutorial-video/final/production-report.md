# דוח הפקה — סרטון הדרכה "קלי קלוח"

## תוצרים
| קובץ | תיאור |
|---|---|
| `kalei-kalut-tutorial.mp4` | הסרטון הראשי עם קריינות עצבית (neural), 1920×1080, 30fps, H.264, אורך 107.5 שניות |
| `kalei-kalut-tutorial-vertical.mp4` | גרסה אנכית לוואטסאפ עם אותה קריינות, 1080×1920 |
| `*-robotic-voice.mp4` | הגרסאות הקודמות עם קול espeak-ng נשי רובוטי (חלופה) |
| `kalei-kalut-tutorial-no-voice.mp4`, `kalei-kalut-tutorial-vertical-no-voice.mp4` | אותן גרסאות ללא קריינות (ערוץ שמע שקט), למקרה שתרצו להקליט קריינות אנושית |
| `kalei-kalut-subtitles.srt` | כתוביות בעברית, מסונכרנות לציר הזמן של הסרטון (הן מוטמעות גם בתמונה) |
| `narration-he.txt` | תסריט הקריינות בעברית, בגוף שני נקבה |

## איך הופק
- **מקור:** האפליקציה האמיתית, מקומית (`npm run dev`), בכיתת הדמה בלבד, עם הסיסמה המתועדת. בלי מוקאפים ובלי תמונות מונפקות.
- **צילום:** סקריפטי Playwright ב־Chromium (`tutorial-video/scripts/scenes.mjs`), 1920×1080, הקלטה רציפה לכל סצנה, סמן עכבר מודגש עם אפקט לחיצה, תנועת עכבר חלקה והשהיות אחרי פעולות. מסך המורה וההקרנה הוקלטו במקביל בשני חלונות. נוסף הקלטה נפרדת של הנייד. הסצנה נשמרת רק אחרי שהסקריפט הסתיים בהצלחה, ויש ניסיון חוזר אוטומטי בכישלון.
- **עריכה:** FFmpeg + שכבות גרפיקה בעברית (RTL, גופן Heebo) שנוצרו ב־Chromium (`scripts/plan.py`). זום אוטומטי אל אזור הפעולה, פיצול מסך (מורה | הקרנה), שלושה פאנלים בסצנת הנייד, כותרות סצנה, לוגו וצבעי האפליקציה. לא נעשה שימוש ב־Remotion; הכלים שנבחרו שקולים.
- **סצנות:** כניסה לכיתה (כולל כניסה אמיתית בסיסמה), פתיחת הקרנה, שקפים ושלבי שיעור וטיימר, מצב כיתה (עבודה שקטה, זוגות), לבבות, חלוקה אקראית לקבוצות עם הקצאת תפקידים אוטומטית והקרנת קבוצות, כובעי חשיבה, שליטה מהנייד.

## מה אומת
- אורך 107.5 שניות (בטווח 100–120), הרזולוציות 1920×1080 ו־1080×1920, בלי קטעים שחורים (`blackdetect` לא זיהה כלום).
- הכתוביות והכותרות מוצגות מימין לשמאל, נבדקו חזותית בפריימים מכל סצנה בשתי הגרסאות.
- **ההדגמות תואמות לפעולות האמיתיות:** שינויי הקרנה (שקף, טיימר, מצב כיתה, לבבות, קבוצות, כובעים) נראים בחלון ההקרנה בעקבות פעולות שבוצעו בחלון המורה.
- **חיבור הנייד אומת:** קוד חיבור אמיתי נוצר במחשב, הוקלד בנייד (דפדפן נפרד, 390 פיקסלים בקירוב), ולחיצה על "הבא" בנייד העבירה את השקף בהקרנה.
- הגרסה האנכית נבדקה חזותית: הממשק קריא בפאנלים הערומים; הטקסט הקטן בלוח התלמידים נשאר קטן.

## מה לא בוצע / מגבלות
- **הקריינות:** מנוע עצבי offline בעברית – `israwave` (מודל VITS ב־ONNX, `thewh1teagle/israwave` v0.1.0) יחד עם מודל הניקוד האוטומטי Nakdimon, שמוסיף ניקוד לכל משפט לפני ההקראה (`scripts/voice2.py`). הקול **גברי** (מאומן על הקלטות SASpeech); בחירת המגדר נמסרה על ידך כלא משנה. הקריינות מתוזמנת אוטומטית לחלונות הכתוביות והעוצמה מנורמלת (ממוצע כ־‎-21dB, שיא ‎-4.4dB). הגרסה הקודמת עם קול espeak-ng נשי אך רובוטי נשמרה כ־`*-robotic-voice.mp4`.
- **לא נבדק בהאזנה:** אין בסביבה כלי להאזנה או זיהוי דיבור, ולכן לא נבדקה ההגייה בפועל (הניקוד האוטומטי נבדק קריאה ותוקנו ידנית שלוש מילים: שקף, מסך, מפעילות). מומלץ להאזין לפני הפצה.
- **רישיון:** מודלי הקול ונתוני האימון (SASpeech) הם פרויקטים פתוחים עם רישיונות משלהם, שייתכן שמגבילים שימוש מסחרי; נא לוודא לפני הפצה רחבה. המודלים לא נכללים במאגר (הורדה מ־GitHub Releases).
- **אין מוזיקת רקע** (אין מקור מורשה זמין). הערוץ השמע כולל קריינות בלבד.
- סצנות 2–7 מתחילות ממצב כניסה שהוזרק (`sessionStorage`) כדי להיות בלתי תלויות; הכניסה האמיתית בסיסמה מוצגת בסצנה הראשונה.
- ההקלטה של Playwright היא 25fps ב־VP8 (סביבת הצילום לא כללה VP9), והסרטון הסופי מקודד מחדש ל־30fps; בחלק מהסצנות מהירות 1.25×. יתכנו סטיות סנכרון של עד כשנייה בין חלונות מסך המורה וההקרנה בשל עומס בהקלטה.
- בדיקת קפיאה אוטומטית סימנה קטעים סטטיים (כרטיס הפתיחה והפסקות קצרות בין פעולות); נבדק חזותית שבהם יש תנועה בלוח התלמידים.
- לא בוצעה פריסה ולא שונו נתוני אמת. השרת רץ בזיכרון מקומי בלבד. הקבצים נדחפו לענף העבודה ולא ל־`main`, בהתאם להוראה "אל תבצע פריסה".

## שחזור
```sh
npm ci && npm run dev            # בטרמינל אחד
cd tutorial-video/tools && npm i # גופן Heebo
node scripts/scenes.mjs          # צילום סצנות (raw/)
# קריינות (israwave.onnx, nakdimon.onnx, espeak-ng-data ב־/tmp/israwave): pip install israwave && python3 scripts/voice2.py
python3 scripts/plan.py prep && node scripts/render_overlays.mjs
python3 scripts/plan.py make land && python3 scripts/plan.py make vert
```
